## Featured Image Specifications

**Format:** 16:9 wide digital illustration
**Rendering:** Digital illustration style — not photorealistic. Soft, atmospheric, cinematic.

### Featured Image Color Palette

| Role | Color | Usage |
|------|-------|-------|
| **Background (dominant)** | Deep twilight (navy to soft purple gradient) | Fills 60-70% of the image. Anchors the mood. |
| **Subject / Accent** | Iridescent glow (cyan, lavender, pearl tones) | The primary subject glows with restrained iridescence. Subtle edge lighting. |
| **Secondary elements** | Complementary warm tones (amber, gold) sparingly | Atmospheric depth, not dominant. |

**Aesthetic:** Modern, clean, restrained iridescence. Soap bubble/holographic quality without being garish. Dark backgrounds let the iridescent elements glow.

### Composition Elements

| Element | Description |
|---------|-------------|
| **Background geometry** | Faint constellation lines, geometric patterns, or circular geometry in the teal sky/background |
| **Grounding surface** | Stone surface, ledge, platform, or rocky terrain. Anchors the subject physically. |
| **Single symbolic subject** | One clear symbolic object per image, centered or center-left/right. No clutter. |
| **Atmospheric depth** | Haze, fog, particle effects. Cinematic shallow depth of field. |

### Prompt Template

```
A wide 16:9 digital illustration in a mystical, atmospheric style. Deep twilight
background (dark navy to soft purple gradient) with restrained iridescent accent
lighting in cyan, lavender, and pearl tones. [COMPOSITION]: [SUBJECT DESCRIPTION].
Faint constellation lines and geometric patterns in the dark background. Subtle
iridescent glow on edges and key elements. Atmospheric depth, cinematic lighting,
shallow depth of field. Modern, clean aesthetic. No text, no people, no photorealism.
```

## Notes

- **Updated 2026-02-13:** Shifted from teal/amber palette to iridescent (cyan/lavender/pearl) aesthetic matching the new brand identity. Featured images now use restrained iridescence with dark twilight backgrounds.
- The featured images and UI now share the same iridescent color language — creating visual cohesion across the brand.
- Each image should feel like it belongs in the same room as the others. When generating new images, compare against the existing set before finalizing.
- Avoid photorealism — the illustrated style allows symbolic subjects to glow and emerge from atmosphere in a way that photorealism fights against.
- **Restraint is key:** Iridescence should be subtle and sophisticated, not garish. Soap bubble quality, not rainbow explosion.
- ChatGPT loves candles. Small functional candles as light sources are acceptable; prominent ritual candles are not.
