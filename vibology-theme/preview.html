Welcome to Vibology Ghost Theme

Theme Preview
Jan 20, 2026 5 min read

Typography & Content

This is a preview of the Vibology Ghost theme. The theme features a clean, modern design with excellent typography using the Cabin font family. It includes full dark mode support, responsive layouts, and comprehensive accessibility features.

Key Features

  • WCAG AA compliant accessibility (11.2:1 contrast ratio)
  • Smooth animations and micro-interactions
  • Comprehensive Ghost card support
  • Syntax highlighting with Prism.js
  • Table of Contents generation
  • Image lightbox and lazy loading
  • Skip links and focus management
  • Reduced motion support

Code Example

// Example JavaScript code with line numbers
function initDarkMode() {
  const theme = localStorage.getItem('theme') || 'auto';

  function applyTheme(themeValue) {
    if (themeValue === 'auto') {
      const prefersDark = window.matchMedia('(prefers-color-scheme: dark)').matches;
      document.documentElement.setAttribute('data-theme', prefersDark ? 'dark' : 'light');
    } else {
      document.documentElement.setAttribute('data-theme', themeValue);
    }
  }

  applyTheme(theme);
}

initDarkMode();
